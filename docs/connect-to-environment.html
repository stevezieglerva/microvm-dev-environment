MicroVM Dev Environment · Quick start

Connect to your development environment

Sign in through the browser terminal. Your personal MicroVM starts when you first log in, and your home directory persists between sessions.

Open the deployed terminal CloudFront app · stack ipad-claude · us-east-1

Sign in from a browser

  1. Select the AWS account used for this stack

    The commands below create a Cognito login in that account. Set the same AWS profile you used for deployment:

    export AWS_PROFILE=<your-profile>
export AWS_REGION=us-east-1

  2. Create your app login if you do not already have one

    The user pool is us-east-1_9l2eaxdt5. Check with your stack administrator if unsure whether your account already has a user. Cognito self-signup is disabled.

    aws cognito-idp admin-create-user \
  --user-pool-id us-east-1_9l2eaxdt5 \
  --username you@example.com \
  --user-attributes Name=email,Value=you@example.com Name=email_verified,Value=true \
  --temporary-password 'Choose-A-Temporary-Password1!'

    Replace the email and temporary password. The first browser sign-in will ask you to choose a permanent password.

  3. Open the app and sign in

    Visit the deployed terminal and use the Cognito email and password. Your MicroVM is provisioned on first login; later visits return to your persistent home.

  4. Sign in to Kiro if you use it

    In the terminal, run kiro-cli login. Follow the device-flow URL and code in any browser. This is a separate Kiro account sign-in; its session persists in your home directory.

Need another user? Cognito users are created by an AWS administrator. The repository README describes fetching the stack's CreateUserCommand output and using it for each user.

Optional: connect from your local terminal

The MicroVM has no SSH endpoint. The repo's helper uses the service's SHELL ingress connector. Sign in to the browser app at least once first so your VM exists.

export AWS_PROFILE=<your-profile> AWS_REGION=us-east-1
cd tools && npm install && cd ..   # first time only
node tools/exec.js --user you@example.com

This opens an interactive shell as coder. Use Ctrl+C twice to disconnect. See the repository Operations guide for the root-shell option and one-off remote commands.
